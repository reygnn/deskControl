## A. Defects

0. **Several workspace groups are mixed.** Coordinates are unique only within a
   group, and deskControl keeps no group. A compositor with a group per output gets
   one set of buttons, interleaved, with two shown as current. mwc sends one group;
   left as it is and written down in CAVEATS.
1. **A 2D grid came out column by column.** Only the first coordinate was kept. y is
   kept and the buttons are sorted by y, then x.
2. **The arrows and the wheel stopped before a desktop that can't be switched to**,
   for good. `next_switchable()` passes over it; Home and End go to the first and last
   that can be switched to.
3. **A press on such a desktop drew the button pushed in**, though the release did
   nothing. `switchable()` decides arming as well.
4. **"no desktops" showed as "no de..."**: without a button the window was sized for
   an empty one. `layout()` makes room for the placeholder.
5. **A failed poll() was reported as "Success".** libwayland records no error for it;
   its errno is passed on.
